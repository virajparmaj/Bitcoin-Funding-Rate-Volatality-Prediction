# Executed study artifacts

Start with [REPORT.md](REPORT.md). These outputs describe a retrospective single-contract funding study, not an untouched confirmatory experiment or trading backtest.

| Artifact | Purpose |
|---|---|
| `coverage.json` | Source, event and origin admission counts |
| `manifest.json` | Execution-time code/config/source hashes, environment and public archive URLs |
| `selection.json` | Validation-selected parameters and training-input identity |
| `validation_candidates.json` | Every declared validation candidate and error |
| `folds.csv` | Fit times, train-label maturity and earliest evaluation origins |
| `fold_boundary_exclusions.csv` | Decisions preceding the monthly fit, removed explicitly |
| `origin_exclusions.csv`, `ticker_exclusions.csv`, `delay_exclusions.csv` | Data admission failures and warm-up exclusions |
| `forecast_artifact_manifest.json` | Hashes binding reports to local saved predictions and selection |
| `scores.csv` | Paired gains, pointwise intervals, block sensitivities and secondary adjusted tests |
| `paired_contrasts.csv` | Horizon, feature, delay and label-proxy paired comparisons |
| `proxy_label_scores.csv` | Identical predictions scored against final indications instead of actual labels |
| `state_quarter_scores.csv` | Descriptive conditional scores, not confirmatory subgroup claims |
| `staleness_scores.csv` | Matched 30/60/65-minute age-limit samples |
| `publication_delay_sensitivity.json` | Origin/history/fold invariance under 0/5/15-minute assumptions |
| `lead_time.png` | Measured error and incremental-gain figure |

The execution manifest was recorded before model evaluation. Reporting/provenance code was completed while the forecasts ran; the artifact manifest records the exact reporting code separately. A later code-only packaging change does not imply the earlier code hash described that change. Reproduction uses the frozen selection identity for all modeling/data code and records final report hashes.

`panel.csv.gz`, `predictions.csv.gz` and `baseline_predictions.csv.gz` remain local and Git-ignored pending redistribution review. They are regenerated by the documented CLI. The original input CSV is already tracked in the repository; this PR does not add or alter it. Existing inclusion does not establish redistribution rights.

The `predictions.csv.gz` ledger includes event/origin/source times, row IDs, labels, indication, forecasts, model/variant, fit time, age and units. Losses and tables can be reconstructed from this file. Never mix these settlement-level scores with the original next-row RF results.

`forecast_replay.json` records a replay of all primary four-hour ridge folds and the first four-hour RF fold from the serialized panel. This checks saved numerical outputs and fold alignment; it is not independent market replication. Reproduce it with `v2/.venv/bin/python -m v2.experiments.verify_saved_forecasts` after the model stage.
